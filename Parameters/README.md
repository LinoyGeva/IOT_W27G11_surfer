# Parameter catalog

Record implemented public configuration here. Actual values and source locations are pending implementation.

| Area | Parameters to document |
| --- | --- |
| Devices | Rider/device assignment, connection timeout and reconnect policy |
| Telemetry | Expected intervals, stale thresholds and display units |
| HUD | Update rate |
| Storage and sync | Queue capacity, retention, upload interval and public endpoint |
| Motion | Calibration, sampling rate and analysis window |

For each parameter, record its name, purpose, value/default, units, source location and whether a change requires restart or rebuild. Secrets are documented separately through the component templates.
