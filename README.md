## AeroVision PoC Project by: XXXXX

## Details about the project

AeroVision PoC is a smart windsurfing training system. A headless cellular hub
collects BLE telemetry and streams it to an Everysight HUD and the cloud. 

## Folder description

* `ESP32`: source code for the ESP side (firmware).
* `Documentation`: wiring diagram and basic operating instructions.
* `Unit Tests`: tests for individual hardware components (input/output devices).
* `flutter_app`: Dart code for the Flutter app.
* `Parameters`: description of parameters and settings that can be modified in the code.
* `Assets`: 3D-printed parts, audio files, and connection-diagram assets.
